#  HUH? CAT 🐱

An online cat game featuring multiple mini-games that support both **single-player** and **multiplayer** modes.

## 🎮 Features

- 🐾 Multiple cat-themed mini-games
- 👤 **Single-player Mode** - Play solo at your own pace.
- 👥 **Multiplayer Mode** - Play and compete with other players online.
- 🎨 Fun and engaging cat-themed experience
